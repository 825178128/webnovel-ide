# UI 信息架构

版本: v0.1
日期: 2026-05-26
阶段: Phase 0 / MVP UI 设计
研发分支: v1-development

## 1. 设计目标

MVP UI 需要服务一个核心动作：

> 作者在同一个工作台里管理作品信息、写章节、查看人物设定，并调用 AI 辅助。

设计关键词：

- 专业。
- 安静。
- 高信息密度。
- 写作优先。
- 长篇管理清晰。
- AI 是辅助面板，不是主界面。

第一版不做营销型首页，不做夸张视觉，不做复杂装饰。界面应更接近专业工具，而不是内容社区。

## 2. 页面结构总览

MVP 页面：

```text
/projects
  作品列表

/projects/new
  创建作品

/projects/:projectId/workspace
  作品工作台

/projects/:projectId/settings
  作品设置

/settings/ai
  AI 配置
```

开发期也可以把创建作品、作品设置、AI 配置做成弹窗或抽屉。最终页面路径仍按上面保留。

## 3. 全局布局原则

### 3.1 桌面优先

MVP 优先支持桌面端宽屏体验。

推荐最小舒适宽度：

- 1280px 及以上。

小屏策略：

- 1024px 以下可以折叠右侧 AI 面板。
- 移动端暂不作为 MVP 核心体验。

### 3.2 信息层级

优先级从高到低：

1. 当前正在写的章节正文。
2. 当前章节目标、字数、保存状态。
3. 相关人物、相关设定。
4. AI 辅助输出。
5. 作品级管理入口。

### 3.3 视觉风格

建议风格：

- 深浅主题后续支持，MVP 可先做浅色。
- 背景用中性灰白。
- 主编辑区保持高可读性。
- 按钮和状态色克制使用。
- 卡片边角控制在 8px 以内。

## 4. 作品列表页

### 4.1 页面目标

让用户快速看到已有作品，并创建或进入作品。

### 4.2 页面结构

```text
顶部栏
  - 产品名
  - AI 配置入口

主区域
  - 页面标题：作品
  - 创建作品按钮
  - 作品列表

作品卡片 / 行项目
  - 作品名
  - 题材 / 目标平台
  - 总字数
  - 章节数
  - 最近更新时间
  - 进入工作台按钮
```

### 4.3 空状态

当没有作品：

- 显示创建作品按钮。
- 显示一句短提示：创建第一本作品，开始搭建你的连载工作台。

## 5. 创建作品页 / 弹窗

### 5.1 表单字段

必填：

- 作品名。

选填：

- 题材/类型。
- 简介。
- 目标平台。
- 目标字数。
- 更新目标。

### 5.2 操作

- 创建并进入工作台。
- 取消。

### 5.3 后续预留

后续可以加入：

- AI 生成简介。
- AI 分析卖点。
- 平台模板选择。

MVP 可先不实现。

## 6. 作品工作台整体布局

### 6.1 三栏结构

```text
┌────────────────────────────────────────────────────────────────────┐
│ 顶部栏：作品名 / 保存状态 / 当前字数 / 今日目标 / 设置 / 导出       │
├──────────────┬────────────────────────────────────┬────────────────┤
│ 左侧导航     │ 中间主编辑区                       │ 右侧上下文 AI  │
│ 260px        │ minmax(560px, 1fr)                 │ 360px          │
│              │                                    │                │
│ 章节树       │ 章节编辑器                         │ 当前章节信息   │
│ 人物库       │ 人物详情                           │ 相关人物       │
│ 设定库       │ 设定详情                           │ 相关设定       │
│ 导出入口     │                                    │ AI 助手        │
└──────────────┴────────────────────────────────────┴────────────────┘
```

建议尺寸：

- 左侧栏：260px。
- 右侧栏：360px。
- 顶部栏：48px 到 56px。
- 中间编辑区自适应。

### 6.2 顶部栏

内容：

- 返回作品列表。
- 当前作品名。
- 当前章节标题，若正在编辑章节。
- 保存状态：已保存 / 保存中 / 保存失败。
- 当前章节字数。
- 今日目标进度。
- 导出按钮。
- 作品设置按钮。

顶部栏不承载复杂导航，避免干扰写作。

## 7. 左侧项目导航

### 7.1 一级区域

左侧包含四个固定区域：

1. 章节。
2. 人物。
3. 设定。
4. 导出。

第一版可以做成垂直分组，也可以用顶部小图标切换面板。为减少复杂度，MVP 建议用垂直分组。

### 7.2 章节树

显示：

- 卷。
- 章节。
- 章节状态。
- 当前选中章节。
- 章节字数，可选。

操作：

- 新增卷。
- 新增章节。
- 重命名章节。
- 删除章节。
- 拖拽排序，MVP 可后置；第一版可先用上移/下移。

章节状态视觉：

- 草稿：灰色。
- 写作中：蓝色。
- 待修改：橙色。
- 已完成：绿色。

### 7.3 人物区域

显示：

- 人物列表。
- 搜索框，MVP 可选。
- 新增人物按钮。

点击人物后，中间主区显示人物详情。

### 7.4 设定区域

显示：

- 设定分类。
- 设定列表。
- 新增设定按钮。

点击设定后，中间主区显示设定详情。

## 8. 中间主编辑区

中间区域根据当前选择显示三类视图。

### 8.1 章节编辑视图

结构：

```text
章节标题输入
章节状态选择
章节目标输入
正文编辑器
底部字数 / 保存状态
```

必要控件：

- 标题输入。
- 状态选择。
- 章节目标文本框。
- 正文编辑器。
- 手动保存按钮。
- 总结本章按钮。

“总结本章”是 MVP 的轻量入口，后续可扩展为“完成本章 / 自动梳理”。

### 8.2 人物详情视图

结构：

```text
人物基础信息
人物设定字段
当前状态
备注
关联章节
```

控件：

- 姓名。
- 身份。
- 阵营/势力。
- 性格关键词。
- 目标/欲望。
- 能力/特长。
- 口吻特点。
- 当前状态。
- 备注。

### 8.3 设定详情视图

结构：

```text
设定标题
分类
重要程度
设定内容
备注
关联章节
```

控件：

- 标题。
- 分类选择。
- 重要程度选择。
- 内容文本框。
- 备注。

## 9. 右侧上下文与 AI 面板

右侧面板分为两块：

1. 上下文。
2. AI 助手。

### 9.1 当前章节信息

显示：

- 标题。
- 状态。
- 字数。
- 章节目标。
- 本章摘要。

操作：

- 编辑章节目标。
- 保存/更新本章摘要。

### 9.2 相关人物

显示：

- 当前章节关联人物。
- 人物当前状态。
- 人物口吻特点。

操作：

- 添加人物。
- 移除人物。
- 点击跳转人物详情。

### 9.3 相关设定

显示：

- 当前章节关联设定。
- 分类。
- 重要程度。

操作：

- 添加设定。
- 移除设定。
- 点击跳转设定详情。

### 9.4 AI 助手

结构：

```text
任务类型选择
用户指令输入
上下文预览
生成按钮
输出结果
插入正文
复制
```

任务类型：

- 续写。
- 润色。
- 总结。
- 改写。

AI 输出区规则：

- 输出结果不直接覆盖正文。
- 插入正文必须由用户点击确认。
- 润色/改写可提供替换选中文本入口。

### 9.5 AI 未配置状态

显示：

- AI 未配置提示。
- 前往 AI 配置按钮。
- 开发期可提供模拟输出开关。

## 10. 作品设置页

字段：

- 作品名。
- 题材/类型。
- 简介。
- 目标平台。
- 目标字数。
- 更新目标。

操作：

- 保存。
- 取消。
- 删除作品。

删除作品需要二次确认。

## 11. AI 配置页

字段：

- Provider。
- API Key。
- Model。
- Base URL。

操作：

- 保存配置。
- 测试连接。
- 清除配置。

安全说明：

- MVP 本地原型可暂存本地。
- 全栈 MVP 应通过后端代理调用，避免前端暴露密钥。

## 13. MVP UI 验收

- [ ] 用户进入作品列表后能清楚看到创建作品入口。
- [ ] 用户进入工作台后能同时看到章节树、正文编辑器和 AI 面板。
- [ ] 用户可以在工作台内切换章节、人物、设定。
- [ ] 当前章节字数和保存状态始终可见。
- [ ] 右侧面板能展示当前章节的相关人物和设定。
- [ ] AI 输出不会遮挡正文。
- [ ] “总结本章”入口可见，但不强制用户使用。
- [ ] 导出入口可找到。
- [ ] 1024px 以下右侧面板可折叠。
